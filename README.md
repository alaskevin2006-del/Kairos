# Kairos 1.2 — Markdown 工作空间

在 1.1 的文档事务、版本历史、模型连接与账号隔离上改造。四个页面为总览、秘书、目标、日记。

## 文档与页面

- `_attention.md`：当前关注与时间入口；分组是状态含义，不将①②③④当作数值优先级。
- `matters/`：统一事项；含 `#长期` 的文档进入目标，其余仍可从日程或文件列表打开。
- `journal/dairy/`：本人日记；`journal/AI/`：独立 AI 分析。日记页保留作者区别。
- `sources/`：原始材料，不从通知自动生成承诺。HTML 课表保存在 `sources/courses.html`。
- `AGENTS.md`：当前空间业务规则参考，每次秘书请求显式加载；权限、路径、版本由代码验证。

不创建旧版目录。个人资料不包含在应用仓库中。保留 `.obsidian/` 等外部配置，程序不扫描或改写隐藏目录。

## 时间、Attention 与索引

支持 `YYYY-MM-DD`、`YYYY-MM-DD HH:mm` 和 `HH:mm–HH:mm`，北京时间。仅有日期的截止时刻未知；午夜截止保留实际日期和 00:00。过去但未确认的项目进入待核实，不自动完成。

Attention 链接解析为精确的相对路径与标题锚点，不按同名文件猜测。链接主题以 Attention 作为日程投影，不再解析同一文档背景生成重复事件。未引用主题中的明确日期复选框也能进入日程。原文日期无法核对时显示警告。

人工或 AI 提交经过同一事务层，唯一对应、旧状态一致的行动更新可连同 Attention 原子提交；歧义项保留并提示人工核对。编辑器支持源码、阅读预览、草稿、冲突比较、删除与历史恢复。文件事实以 Markdown 为准，缓存可重建。

首次扫描正文，随后定期核对文件属性，仅重读变化文件；新增、删除、重命名也会更新索引。不会每次把所有正文发给模型。秘书先搜索最多 15 个候选摘要，再读取必要原文，单轮总读取限制 7 万字符。普通页面刷新不调用 AI。

## 日程与课表

周历保留完整 24 小时，每小时 60 像素，初始滚动到 08:00。重叠组展示一个代表卡片和其余数量，点击打开当天完整列表；不把卡片无限切成窄列。课程、个人事项和截止全部保留，日期未知时刻项目放在当天列表后段。月历最多 4 条，其余数量展开。

文件入口支持上传、替换 HTML。复用原有 P/SEG/C 字面量课表解析器，不执行 HTML 中的脚本。不支持任意学校 HTML 格式，未识别到课程会明确报错并保留旧课表。

## 本地启动

```powershell
npm ci
npm run build
npm run desktop
```

本机桌面提供「Kairos 本地客户端」快捷方式。菜单「在浏览器打开本地空间」可打开同一个运行中的本地服务与目录；浏览器和 Electron 共享原文件。设置可选择管理目录、课表 HTML 路径。

独立本地 Web：设置 `KAIROS_LOCAL=1`、`KAIROS_SOURCE` 为明确的本地目录，再执行 `npm start`，使用终端给出的本地入口登录。默认仅监听 127.0.0.1。本地入口只用于当前电脑，不向外分享。

## 服务器

`npm run build` 后用 Node.js 22+ 运行 `npm start`。沿用 DATA_DIR、HOST、PORT、KAIROS_PUBLIC_PATH 与既有账号初始化环境变量。每个账号在 DATA_DIR/spaces/<id>/documents/ 中独立存储文件。管理员仅管理账号。

本地和服务器不自动同步。客户端无定时上传任务，旧 `/api/sync`、`/api/workspace/sync` 和快照导入入口返回 410。现有快照保留用于恢复，不全量覆盖个人空间。在服务器网页用文件入口新建或编辑当前账号文件。

## 验证与恢复

```powershell
npm test
npm run build
node_modules/electron/dist/electron.exe scripts/ui-check.cjs
npm run package
```

UI 验证仅使用 `.private/ui-check` 中的合成数据，检查密集课程、重叠任务、窄窗口、日记及直接编辑保存，输出截图和报告。版本历史存于账号私有目录；撤销校验文件当前版本，不覆盖后续修改。

改造前的应用与本机管理文档备份位于本地 `.private/before-2026-11-07/`，不进仓库或安装包。尚未实现通用富文本所见即所得编辑；使用 Markdown 源码与阅读预览保证原文保真。外部编辑采用短周期属性核对，不依赖不稳定的系统文件监听。
